# Assets & Licences

No paid or downloaded assets are used. Everything is procedural or
self-authored with free tools (Godot, Blender).

| Asset | Source | Licence |
|---|---|---|
| All textures (brick, concrete, grass, paving, asphalt, roof, wood, marble, track, flowers, water, shirt patterns) | Procedurally generated at runtime in `scripts/texgen.gd` | Project's own work |
| Student characters (male + female rigs, 19 bones, idle/walk/run/sit/talk clips, 8 hair styles, backpack) | Modelled + animated in **Blender 4.5.15 LTS** via the bpy script `tools/build_characters.py`, exported as `assets/characters/student_male.glb` / `student_female.glb` | Project's own work |
| All other 3D models (buildings, bus, auto-rickshaw, cars, scooters, bicycles, trees, props) | Built from Godot primitive meshes in code (`scripts/world.gd`) | Project's own work |
| Game icon | Hand-written SVG (`icon.svg`) | Project's own work |
| Fonts | Godot engine default font | Godot (MIT) |

Engines/tools: Godot 4.3 stable (MIT) — https://godotengine.org/license ·
Blender 4.5.15 LTS (GPL, used as a tool only; exported models are the
project's own work) — https://www.blender.org
